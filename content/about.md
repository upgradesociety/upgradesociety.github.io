Upgrade Society is an independent publishing and experimentation project.

## Editorial freedom

The project is intentionally allowed to experiment. A scenario is not a promise. A research note is not doctrine. A personal essay is not automatically a project position. A canonical page is maintained and may change when the underlying thinking changes.

This separation is important: it lets the project be serious without becoming rigid.

## Provenance and versions

Upgrade Society uses **Content Studio / Content Manager** as the authoritative content registry. Every substantive page receives a stable `content_id`, immutable content versions, editorial state and explicit relationships to other content.

The Hugo/GitHub repository is a **publishing surface**. It should never become a second untracked source of truth.

## Publishing identity

Pages in this release are published by **[Citizen Upgrade](/about/citizen-upgrade/)** under the **Upgrade Society** project identity.

## Corrections

Substantive factual pages should preserve sources, review dates and corrections. Scenarios should preserve assumptions, uncertainty, alternatives and falsifiers. Earlier versions should remain recoverable rather than being rewritten out of history.
